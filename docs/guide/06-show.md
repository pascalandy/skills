# Turn your work into something to show

Some work lands better as a page than as a chat answer. In this page you use `html-mode` to make a one-page summary, a slide deck, a diagram, and a work plan. Each one is a single HTML file that opens in your web browser.

## Make a one-page summary with `html-mode ; artifact`

```text
html-mode ; artifact. Turn this report into a one-page summary for my director: [paste the report]
```

The agent builds one page with your content, a clear layout, and readable colours. It works on a phone and on a computer.

## Make a slide deck with `html-mode ; slides`

```text
html-mode ; slides. Turn these notes into a 6-slide pitch for the bank: [paste your notes]
```

The agent tells one story, one screen at a time. Open the file and use the arrow keys to move between slides.

## Draw a diagram with `html-mode ; diagram`

```text
html-mode ; diagram. Show how a customer order moves from our website to delivery.
```

The agent draws how the parts relate: who hands what to whom, and in what order.

## Lay out a work plan with `html-mode ; plan`

```text
html-mode ; plan. Show this project's steps, owners, and deadlines: [paste the plan]
```

The agent shows the commitments, their order, who owns each one, what depends on what, and the risks.

## Open the file

Some chat apps show a preview of the page right in the chat. Otherwise, download the file and open it in your web browser.

In a chat app, the agent can't open the page to check it. It tells you which checks it couldn't run. Look at the page yourself on a phone and on a computer, then ask for changes in plain words: "The table is too wide on my phone."

Two more routes sketch screens for an app or a website: `wireframe` for a rough layout and `prototype` for a polished mockup.

**Pitfall:** ask for one page per request. A summary, a deck, and a diagram in one request get three rushed results. Ask for the summary, review it, then ask for the deck.

# Artifact

An HTML presentation has a narrower owner. Switch to the [slides playbook](slides.md) instead of adapting this generic playbook.

1. Choose the reading or operating mode. For reports, briefs, explainers, and comparisons, read [documents and presentations](../references/documents-and-presentations.md). For calculators, editors, and tools, read [interfaces](../references/interfaces.md). For embedded relational diagrams, read [diagram techniques](../references/diagram-techniques.md). Finish when the form fits what the audience must understand or do.
2. Arrange content around that purpose. A mixed report with a chart remains a report when evidence and interpretation are the main task. Give each region a role and keep observations, interpretations, recommendations, and uncertainty distinguishable. Finish when every region contributes to the stated purpose.
3. Build and run the shared verification from `SKILL.md`. Check the selected reference's form-specific behavior, such as calculator inputs. Finish when the file supports its intended reading or operating mode at both widths.

Return the form chosen, the main visual and interaction decisions, and any assumptions introduced.

# Artifact

For HTML presentations, use the [slides playbook](slides.md).

1. Choose reading or operation. For reports, briefs, explainers, and comparisons, read [documents and presentations](../references/documents-and-presentations.md). For calculators, editors, and tools, read [interfaces](../references/interfaces.md). For relational diagrams, read [diagram techniques](../references/diagram-techniques.md). Finish when the form fits the audience's task.
2. Arrange content for that task. If evidence and interpretation are primary, a report with a chart remains a report. Give each region a role. Separate observations, interpretations, recommendations, and uncertainty. Finish when every region serves the purpose.
3. Build and run shared verification from `SKILL.md`. Check behavior required by the selected reference, such as calculator inputs. Finish when reading or operation works at both widths.

Return the form, main visual and interaction decisions, and assumptions.

# Plan

1. Read the source plan and [document guidance](../references/documents-and-presentations.md). Identify commitments, order, owners, dependencies, risks, acceptance checks, and open questions. Finish when each commitment has a place in the artifact.
2. Structure the document around supported facts. Separate accepted decisions from assumptions and questions. Use tables for repeated fields and exact comparisons. Add timelines, progress, or status only when the source supports them. Improve grammar and hierarchy without changing terminology or scope. Finish when sequence and dependencies match the source.
3. Build and run shared verification. Compare the rendered plan against every source commitment. Check omissions, order, ownership, visible dependencies, and long-content overflow. Finish when every commitment is recognizable and each structural interpretation is stated.

Return structural interpretations and unresolved source questions.

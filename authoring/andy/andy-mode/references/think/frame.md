# Frame

Use this method when solving the stated problem may preserve the real problem, when the analysis feels correct but wrong, or when disagreement rests on an unnamed criterion.

## Method

1. Suspend the provisional verdict when the question is high-stakes, emotionally loaded, binary, or difficult to reverse
2. State the current frame as a question and name what it treats as fixed
3. Reverse-engineer the criterion that would make the obvious answer look correct
4. Ask whether the user would endorse that criterion if it were explicit
5. Identify the underlying need, symptom, or contradiction that the current frame may conceal
6. Form one genuinely different frame by changing the criterion, time horizon, unit of concern, role, or theory of value
7. Re-run only the load-bearing part of the analysis under the alternative frame
8. Compare the results as convergence, resolvable divergence, or genuine aporia

Do not generate a parade of reframings. One credible alternative is enough to test whether the original frame controls the answer.

## Completion criterion

Finish when one of these is true:

- both frames support materially the same answer and confidence increases
- one frame is more appropriate and the reason is explicit
- the criterion itself requires a user decision before analysis can continue
- neither frame has justified priority and the unresolved aporia is stated precisely

Merely rewording the original question does not complete the method. The alternative must be capable of changing the conclusion or the options considered.

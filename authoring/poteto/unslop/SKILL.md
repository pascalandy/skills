# unslop

Before you write or edit text, read the version for its language and follow it:

1. French: [references/french.md](references/french.md)
2. English, or any other language: [references/english.md](references/english.md)

In a text that mixes both, follow the version for the language of the sentences you write.

Use [routing cases](references/routing-cases.md) when changing this routing.

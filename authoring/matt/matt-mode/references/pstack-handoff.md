# PStack handoff

Matt-mode prepares implementation. Poteto-mode performs implementation and runnable prototypes. Planning research and delegation do not transfer execution authority into Matt-mode.

When the user requests implementation, direct them to `poteto-mode` with the existing spec or tickets, agreed decisions, test strategy, acceptance criteria, dependencies, and unresolved blockers. Write a separate handoff document only when requested or needed to carry otherwise missing context.

A completed spec or ready ticket ends the planning task. It does not automatically activate Poteto-mode, begin implementation, merge a PR, or deploy. The implementation workflow retains its own design, verification, and delivery procedures.

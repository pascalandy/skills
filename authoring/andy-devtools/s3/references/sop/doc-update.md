# doc-update

DOC<n> runs this SOP in the worktree of COD<n>, while COD<n> stays idle.

## Update

1. Run 🧰 andy-mode ; docs on the stack's final diff. Done when each doc that describes a behavior the stack changes matches the new behavior
2. Open the docs PR as the top layer of the stack with 🧰 gh-stack. Done when the PR is open, or you report that no doc needed a change

## Fix

- Fix each finding MAIN relays on the docs PR, commit, and push
- Done when each finding is pushed, or reported with the reason it could not be

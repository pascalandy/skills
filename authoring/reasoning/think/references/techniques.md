# Targeted techniques

Read this file only when the primary method stalls or the user explicitly asks for another angle. Select the technique that could expose a named blind spot. Never apply the whole bank by default.

## Focused lenses

| Lens | Question it adds |
|---|---|
| Literal | What was explicitly requested or observed without interpretation |
| Stakeholder | Who else is affected and what would they add |
| Failure | How could the current model or proposal break |
| Temporal | What created the situation and what changes over time |
| Experiential | What would success or failure be like for the person living with it |
| Constraint inversion | What changes if an assumed constraint disappears or becomes extreme |
| Analogical | Which genuinely similar pattern supplies evidence, and where does the analogy break |
| Meta | Is the question itself preserving the problem |

Choose one lens with a reason. A lens that cannot plausibly change the result is decoration.

## Divergence

When the model is trapped in one family of answers, generate a few structurally different candidates. Vary the mechanism, not the wording. Do not invent probability percentages or keep weak ideas to reach a quota.

## Perspective comparison

Compare two real roles, time horizons, units of concern, or theories of value. Re-run the load-bearing question from each. Do not stage a fictional council or claim consensus among simulated personalities.

## Completion criterion

Stop when the added technique changes the model, strengthens it through genuine convergence, or demonstrates that another angle is unlikely to add decision value.

# Compare

Use this method when the user must choose among options and the important work is identifying what can actually reverse the decision.

## Method

1. State the decision, decision owner, deadline, and default if no choice is made when these affect the outcome
2. Remove options that violate hard constraints
3. Identify the few criteria that discriminate among the remaining options
4. Distinguish threshold criteria from preferences and avoid scoring decorative factors
5. Account for downside, reversibility, option value, switching cost, and the value of waiting for more information
6. Compare the options under the base assumptions
7. Change the load-bearing assumptions and locate the conditions under which the recommendation flips
8. Recommend an option, a staged commitment, an experiment, or deliberate deferral

Do not hide judgment behind a weighted matrix. Weights and scores require evidence or an explicit stakeholder choice. When an uncertainty matters more than all other criteria, make it visible instead of averaging it away.

## Completion criterion

Finish when the recommendation, its decisive criteria, and its switching conditions are explicit. If the choice remains unresolved, state exactly which evidence or value judgment would resolve it.

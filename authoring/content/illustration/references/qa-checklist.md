# QA checklist

## Required checks

- The canvas is 16:9 and horizontal
- The background is pure white
- Xiaohei appears in the image
- Xiaohei performs the central action rather than decorating the scene
- The composition uses a new metaphor for the current source rather than copying an example
- The image is strange and inventive without becoming confusing
- The main subject occupies no more than about 60% of the canvas
- The image communicates one central idea
- Labels are few, short, readable, and written in the output language chosen in `SKILL.md`
- The image uses 3 to 5 labels when practical and never more than 8
- Canadian French labels use Canadian terminology and idiom rather than defaulting to European French
- Orange appears only on the main route or arrows
- Red appears only on key points, problems, warnings, or results
- Blue appears only on supporting explanations, feedback, or system state

## Failure signals

Regenerate or edit the image when:

- A type title such as "Common pitfalls", "Workflow", "System architecture", or "Roadmap" appears in the top-left corner
- Xiaohei looks like a mascot, meme, or cute cartoon
- The image resembles a slide, course page, or formal flowchart
- It has too many objects, arrows, or nodes
- Labels become paragraphs
- The background has paper texture, shadows, gradients, beige, or noise
- It contains a realistic application screenshot or futuristic interface
- Labels are in the wrong language, misspelled, or unreadable
- The scene is rigid and lacks an absurd metaphor
- The composition closely resembles an image in `assets/examples/`

## Iteration methods

- If the image is ordinary, make Xiaohei perform the action and add one strange but coherent metaphor
- If it is crowded, remove nodes and keep one action with 3 to 5 short labels
- If it is cute, reinforce "deadpan", "blank serious expression", "not cute", and "not a mascot"
- If it resembles a slide, remove the title, borders, regular grid, and excess arrows, then use a hand-drawn scene
- If it resembles an older example, preserve the idea but replace the main object and Xiaohei's action
- If a few labels are wrong, edit them locally; if many are wrong, regenerate with fewer labels

## Delivery test

A strong image should feel slightly strange, then reveal its structure within a second.

Reject it if the first impression is a tutorial page rather than an absurd product sketch on white paper.

# Documents and presentations

For HTML presentations, use `playbooks/slides.md`. Use the rules below for scrolling documents.

## Documents

Open with the reader's decision or question, then evidence and detail. Keep prose readable. Allow wider regions for tables, timelines, code, and diagrams.

- Align like-for-like attributes in comparisons
- Keep operational prose in document flow, without a card per paragraph
- Use labels and numbering only for real hierarchy or sequence
- For print output, add print styles and keep essential content available without interaction

# FinalizeWithWriteDownPostmortem

Read `references/export-artifacts.md` from the active `pa-doc-update` skill directory for the postmortem export protocol after the lesson capture is final.

## Method

1. Confirm the lesson set is final.
2. Pass the final content through the postmortem profile in `pa-doc-update`'s `references/export-artifacts.md`.
3. Write the artifact to the resolved `export_path` from that profile.
4. Return the folder path, file path, and slug.

# Language and spoken performance

## Literary prose

Use voice, point of view, interiority, syntax, paragraph, description, time compression,
time expansion, and reading rhythm.

**Central diagnostic**

Does the language create an experience that cannot be reduced to a visual summary?

## Oral story, speech, and spoken performance

Use presence, breath, cadence, repetition, anticipation, memory, audience interaction,
gesture, pace variation, and returns to the present.

**Central diagnostic**

Can the story be followed, felt, and retained on first hearing?

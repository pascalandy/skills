# Diagnose

Use this method when observations admit several causal explanations and the next useful move is to distinguish among them.

## Method

1. Define the observed behavior and the expected behavior without embedding a cause in either statement
2. Separate direct observations from interpretations and reports
3. Generate a small set of materially different hypotheses, including the strongest non-obvious alternative
4. For each hypothesis, state what it explains, what it explains poorly, and what new observation it predicts
5. Rank hypotheses by fit and prior plausibility without inventing numerical precision
6. Find the cheapest safe observation or test whose possible outcomes best separate the leading hypotheses
7. State which result would weaken the favored hypothesis

Do not turn diagnosis into execution. Route external fact-finding to research and software reproduction or repair to the `poteto-mode` Bug fix playbook when those actions become the next step.

## Completion criterion

Finish when the leading explanations are distinguishable and one next observation has a clear interpretation under each. If no available observation can discriminate, name the missing access or evidence instead of choosing a cause by confidence alone.

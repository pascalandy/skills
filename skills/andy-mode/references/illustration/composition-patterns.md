# Composition patterns and originality rules

## Basic composition types

Choose one composition type. Do not combine several without a concrete reason.

### Workflow

Use for input -> processing -> output, content production, AI workflows, and automation chains.

Place input on the left, Xiaohei or a strange machine processing it in the middle, and output on the right. Use orange arrows for the main direction.

### System detail

Use for information sources, filters, databases, renderers, and a focused part of an agent system.

Show only 3 to 5 essential components. Xiaohei performs one key operation.

### Before and after

Use for chaos versus order, manual versus automated, scattered versus consolidated, or anxious versus stable.

Put the unstable state on the left and the stable state on the right, connected by an orange arrow. Xiaohei's action may be more exaggerated here.

### Character states

Use for user pain points, a creator's condition, tool overload, information anxiety, or the shift from stuck to moving.

Show 2 to 4 small states, each with one short label.

### Conceptual metaphor

Use for a content factory, information warehouse, mental black box, workflow machine, or automated daily report.

Use one large strange object or machine, a few inputs, and one output. The central object should be memorable.

### Layered method

Use for methodology, system layers, capability stacks, or content-system layers.

Draw stacked boxes rather than a formal pyramid. Xiaohei moves or builds one of the layers.

### Route map

Use for idea-to-launch paths, user journeys, content handoffs, or learning paths.

Draw a curved path with few nodes. Xiaohei walks it or pulls part of it into place.

### Mini comic

Use for failure-to-success sequences, a real process, a dry joke, or change before and after use.

Show 2 to 4 small scenes with one action per panel.

## Inventing an original metaphor

Build a new metaphor from the current source every time. Do not copy an older image.

1. Turn the abstract idea into a physical action such as getting stuck, leaking, becoming heavy, sorting, settling, fermenting, opening, folding, unpacking, or returning
2. Turn the system into a low-tech object such as a broken machine, cardboard box, drawer, pipe, mailbox, odd dial, scale, well, ladder, or strange workstation
3. Make Xiaohei perform the action by getting stuck in the machine, pulling the wrong line, guarding a gate, carrying, repairing, weighing, holding a ladder, recording, or feeding material into an odd device

### Object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, ball of string, gate, turntable, black box, hole punch, pasta roller, clothesline, or strange workstation
- Choose only 1 or 2 objects

### Xiaohei action pool

- Pull, carry, insert, retrieve, press, weigh, sew, cut, twist, guard, push, catch, dismantle, mark, or recycle
- The action must explain the central idea, not add strangeness for its own sake

## No-copy rule

Do not open or reproduce `references/illustration/assets/examples/` by default. These images calibrate line density, whitespace, colour restraint, and Xiaohei's demeanour only.

Unless the user explicitly asks to match or adapt a specific example, do not reuse these compositions:

- Two breakpoints on a conveyor belt
- Xiaohei pulling a decision lever inside a content machine
- Xiaohei as a funnel sorting traffic, trust, and conversion
- Xiaohei cutting a fish-shaped source asset
- Xiaohei pulling a handoff route
- Xiaohei connecting three source layers
- Three Xiaohei characters holding a megaphone, building a bridge, and opening a door
- Xiaohei stamping a handoff-copy toolbox
- Xiaohei holding a sign beside a path of common pitfalls

Change the metaphor even for similar topics. A handoff path could show Xiaohei attaching a loose content tail to a door handle. Content reuse could show Xiaohei pressing one paper ball into several forms instead of cutting a fish.

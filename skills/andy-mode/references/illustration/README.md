# Original skill reference

This directory preserves background material about the origin of the `illustration` skill.
Its contents are archival and are not instructions for the agent. They do not need to be
linked from `playbooks/illustration.md` or loaded when the skill runs.

The skill was adapted from Ian Xiaohei Illustrations by Ian Neo:

- Source: https://github.com/helloianneo/ian-xiaohei-illustrations
- Author: Ian Neo, `helloianneo`
- Website: https://www.ianneo.xyz

The adapted skill keeps the original Xiaohei character and visual language while adding a
Codex workflow, English and Canadian French output, image-tool routing, and generation QA.

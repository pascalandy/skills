# rev-docs

RDOC<n> runs this SOP on the docs PR of DOC<n>, at the top of the stack of COD<n>, and reports as REV in `SKILL.md` says.

Use 🧰 technical-writing to review the docs PR against every change from <base branch> to HEAD. Does each doc match the behavior the stack changes? Did the stack leave a doc stale outside the docs PR? Make sure the docs stay 🧰 concise.

Done when your report lists each finding, or says you found none.
